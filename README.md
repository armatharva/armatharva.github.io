# Atharva's Portfolio

A single-page student portfolio built with plain HTML and CSS. It introduces my current learning goals, practical skills, and small projects.

## View the site

Open `index.html` in a browser to view the portfolio locally. The stylesheet is linked from the page, and the Python project does not need to be installed to view the website.

To run the study-time example with Python 3:

```text
python projects/study-time/analysis.py
```

The CSV contains fictional, synthetic sample values for practice. It does not describe anyone's real study habits.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. Visit the URL GitHub Pages displays after deployment completes.

## Project files

- `index.html` — portfolio content and section navigation.
- `style.css` — colors, layout, responsive rules, and focus styles.
- `projects/study-time/` — Python CSV analysis and its synthetic sample data.
- `learning_log.md` — Copilot learning log and reflection.

No external templates or third-party images are used.
